Direct Projector Output (HDMI / wireless-extended screen)

This is different from the OBS window below — it sends Live straight to your extended screen (HDMI-connected projector, or a wirelessly-extended display like a wireless HDMI dongle or Miracast screen), borderless and fullscreen, with nothing dragged manually. Click once here first so the permission is already granted before service — that way the "📽 Send to Projector" button up top works instantly with one click.

Works in Chrome/Edge. On Firefox/Safari (no screen-detection support), "Send to Projector" still opens the output — just drag it to your second screen and press F11 once; it stays synced automatically after that.

NDI Output (to OBS, stage monitors, secondary projection)

A web page can't broadcast real NDI on its own — NDI requires Vizrt's native SDK, which browsers don't expose to web pages for security reasons. The good news: you don't need HDMI/SDI or any manual IP setup either way — NDI's own network discovery handles that automatically once a real NDI sender is running. Here's the free, standard way to get this presenter onto NDI:

  1. Click "Open OBS Window" above — this opens a clean, borderless output window titled "Express Bible Presenter — Output".
  2. Install the free NDI Tools from ndi.video (one-time, official Vizrt download) and run NDI Screen Capture (Windows/Mac).
  3. In NDI Screen Capture, choose "Express Bible Presenter — Output" from the window list and start it.
  4. That's it — any NDI receiver on your network (OBS Studio's NDI source, ProPresenter, vMix, a stage-monitor NDI decoder, another PC) will now see it appear automatically, no cables, no IP addresses to type in.

If you'd rather go straight through OBS: install the free obs-ndi plugin in OBS Studio, add this app as a Browser Source (link above) or Window Capture of the output window, then enable "Output NDI Source" in OBS — OBS itself becomes the NDI sender for your whole scene.

You're running the desktop companion app, so a true native NDI sender is available — but it depends on an experimental community library, so it may not work on every machine. If it fails, the HDMI/extended-display output above keeps working regardless.
